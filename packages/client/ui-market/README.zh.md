# @deepseek-ai/dsh-client-ui-market

[English](README.md) | 中文

## 概述

市场客户端插件在浏览器页面展示目录技能和连接器，跟踪 Host 的安装状态和连接器状态，允许用户安装、启用、停用、编辑或删除市场技能和个人技能，连接、断开、更新或卸载市场连接器，以及添加、编辑或删除自定义连接器。它挂载所使用的 `market`、`marketSkills` 与 `marketConnectors` Remote 命名空间，并通过 `session` 命名空间在文件管理器中显示技能文件夹。

## 使用此包

将插件与 Web 客户端和 Host 市场 bundle 一起挂载。打开市场面板即可浏览技能分类、查看技能详情、安装技能并管理已安装列表。安装、切换或删除后页面会刷新技能名称和斜杠菜单候选项。

每个已安装技能的详情弹窗都有同一个“更多操作”菜单，无论技能来自市场还是个人文件夹：

- **编辑**：打开新对话，输入框内容为 `/skill-creator 请帮我编辑 /<skill> 这个 skill`，两个名称都是技能引用，不会自动发送。
- **打开文件夹**：在 Host 的文件管理器中选中技能的说明文件。只有 Host 报告有桌面且技能有文件路径时才显示。
- **卸载**：先确认。市场技能通过市场卸载；个人技能会删除其文件夹。

Host 挂载了连接器类型时才显示“连接器”页签。**连接**会先安装尚未安装的连接器；第一次连接时显示连接器要运行的程序，用户接受后才启动。接受过的连接器可以直接在卡片上开关。详情弹窗显示连接器状态和启动失败原因，并提供重试、更新和卸载。

**添加连接器**用来添加用户自己配置的 MCP 服务：可以粘贴 MCP 项目给出的 JSON，一次可以有多个服务，保存前逐个列出并标出有问题的；也可以手动填写一个服务，包括整行命令或 URL、每行一个的环境变量或 Headers、超时，下方显示对应的 JSON。自定义连接器排在网格最前面，带“自定义”标签和命令或 URL，可以直接在卡片上开关。编辑时类型固定，要换类型就删除后重新添加。它的详情弹窗默认遮住环境变量和 Headers 的值，可以点开查看，并提供编辑和删除。启动失败时显示常见原因的提示、Host 给出的原因，以及程序最后几行 stderr；**让助手诊断**会新开一个对话，预填连接器的配置和失败信息，环境变量和 Headers 只列名字、不带值。

技能或连接器安装期间，卡片上显示进度条，详情弹窗显示当前步骤和进度条：先是已下载的 MB 数，再是已解压的文件数。

<a id="understand-the-implementation"></a>
## 实现说明

客户端使用一个可观察 store 保存目录和已安装技能流。用户操作调用类型化 Remote 方法，并通过页面和持久 toast 展示成功或失败。调用和流走不同的通道，所以连接器调用的结果可能比连接器流里更新的一帧晚到；store 接受流里的每一帧，丢弃 `revision` 比当前显示的小的调用结果，这样已经再次失败的重试不会一直停在“启动中”。插件提供主面板、导航入口，以及 `ui-skill` 使用的技能显示名称。

<a id="model-experience"></a>
## 模型体验

### 已安装技能发现

#### 模型看到的内容

页面不增加提示词。启用技能会改变 `ctx.skills`，因此已有技能目录可以根据调用策略向模型展示它。

#### Token 影响

浏览页面时没有影响。之后调用技能时，现有技能消费者负责计算指令正文。

#### KV Cache 影响

没有直接影响；面向模型的技能内容由 Host 技能消费者负责。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 页面需要 Host 提供市场 Remote 命名空间；目录端点离线时会显示最近一次可用的目录。
- 在页面上删除个人技能后无法撤销；文件会被直接删除，不会进入回收站。
- 编辑依赖 `skill-creator` 技能；组合中没有它时，引用会作为普通文本发送。
